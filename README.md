<h1>Epitech Projects with AI</h1>
<p>
  This repository is my attempt to complete Epitech school projects using modern AI tools.  
  The goal is not only to replicate the work but to explore how advanced AI systems can assist, accelerate,  
  and reshape the way we approach complex programming challenges.
</p>

<h2>📂 Repository Structure</h2>
<ul>
  <li><b>best/</b> – manually verified best-quality projects</li>
  <li><b>claude/</b> – projects by Claude Sonnet 4.1 (Claude-Code) with my assistance</li>
  <li><b>gpt/</b> – projects by GPT-5 Medium (Codex) with my assistance</li>
  <li><b>full_llm_gpt/</b> – projects fully auto-generated by GPT-5 Medium (Codex)</li>
  <li><b>full_llm_claude/</b> – projects fully auto-generated by Claude Sonnet 4.1 (Claude-Code)</li>
  <li><b>gemini/</b> – projects by Gemini 2.5 Pro (Gemini-cli), aborted due to token limits</li>
  <li><b>utils/</b> – helper scripts and automation tools</li>
</ul>

<h2>⚙️ Method</h2>
<ol>
  <li><b>Setup:</b> Run LLMs inside tmux sessions with Codex/Claude-Code/Gemini-cli. Launch recursive prompt to read project PDFs, create <code>_roro</code> dirs, and build compilable deliverables with tests.</li>
  <li><b>Supervision:</b> Scripts keep sessions alive (<code>continue</code> script). Manual monitoring and corrections applied when needed.</li>
  <li><b>Selection:</b> Best projects are moved to <code>best/</code> for reference.</li>
</ol>

<h2>📝 Rules</h2>
<ul>
  <li>Strict Epitech coding style: headers, snake_case, ≤80 cols, ≤20 lines per function, etc.</li>
  <li>Makefile targets: all, clean, fclean, re, tests_run (Criterion + coverage)</li>
  <li>Deliverables: compilable with <code>make</code>, at least one test in <code>tests/</code></li>
</ul>
