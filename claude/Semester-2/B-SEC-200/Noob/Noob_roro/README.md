# N.O.O.B - Noob-Oriented Operations on Binaries

## Description
B-SEC-200 Security project focused on binary exploitation and CTF challenges.

## Project Structure
This project is a Capture The Flag (CTF) competition involving:
- Binary exploitation
- Flag discovery
- Security analysis
- Reverse engineering

## Technical Requirements
- GDB, ltrace, hexdump, objdump for debugging
- Custom scripts for exploitation
- Manual exploitation techniques

## Challenge Categories
- Easy challenges
- Intermediate challenges  
- Hard challenges

## Learning Objectives
- Binary security analysis
- Reverse engineering techniques
- Exploitation methodology
- Security vulnerability assessment

## Implementation Status
This is a CTF platform project requiring:
1. Team registration on NOOB interface
2. Office365 authentication
3. Completion on external platform
4. No local implementation needed

Note: This project takes place entirely on the NOOB platform interface, not as a local implementation.
