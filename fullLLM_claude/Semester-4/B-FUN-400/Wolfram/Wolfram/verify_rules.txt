Key Implementation Details:
===========================

1. Infinite Space: The implementation uses a finite list with implicit dead cells
   at boundaries, expanding as needed.

2. Pattern Matching: Each rule is implemented using exhaustive pattern matching
   on all 8 possible three-cell neighborhoods.

3. Window Display: The display function calculates a window centered around the
   middle of the generation, with optional movement offset.

4. Pure Functions: All functions are pure with no side effects, following
   functional programming principles.

5. Higher-Order Functions: Uses map, iterate, and other HOFs for generation
   sequences and transformations.
