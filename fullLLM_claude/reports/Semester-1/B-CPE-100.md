## Description
Le C Pool est la fondation du cursus Epitech. Ce module couvre les bases du système UNIX, les éléments fondamentaux du langage C, les Makefiles et quelques structures de données. Il comprend plusieurs projets pratiques :
- Count_island : Algorithme de comptage d'îles
- Firtree : Génération d'arbres ASCII
- MatchNmatch : Système de correspondances de patterns
- Pool : Exercices quotidiens (12 jours)
- Rushs : Mini-projets de weekend (2 jours)
- Star : Génération de formes en étoile
- WorkshopLib : Création de bibliothèque personnalisée
