- **Type** : Programmation graphique C - Jeux et animations 2D
- **Langage** : C (avec CSFML)

## Description
Module d'initiation à la programmation graphique axé sur création d'images/animations et gestion de scènes. Préparation aux enjeux principaux du MyRPG. Deux axes principaux :
1. Effets spéciaux graphiques, rendu 2D/3D, gestion des collisions, gestion d'entités (composant mathématique)
2. Gameplay, animations avec sprites, cohérence du monde virtuel, durée de vie du jeu (aspect "jeu")

Projets :
- MyHunter : Jeu avec caméra fixe, tir sur éléments mobiles
- MyRadar : Détection de collision entre avions dans espace 2D
- MyRunner : Jeu de plateforme/runner
- MyScreensaver : Économiseur d'écran avec animations
