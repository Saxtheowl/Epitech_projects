# SYNTHÈSE COMPLÈTE - SEMESTER-5 EPITECH

## Vue d'ensemble du Semester-5

Le **Semester-5** représente l'aboutissement de la formation Epitech, avec un niveau **Master/Expert** préparant directement à l'entrée dans le monde professionnel ou à la poursuite en recherche avancée.

### Statistiques globales
- **Total crédits** : 23 crédits + modules professionnels
- **Modules techniques** : 5 modules principaux
- **Projets majeurs** : 6 projets de niveau industriel
- **Durée estimée** : 1 semestre intensif (6 mois)
- **Niveau** : Master 1 / Expert

## Analyse détaillée par domaine

### 1. Intelligence Artificielle (B-AIA-500)
**Projet** : Gomoku - IA de jeu avancée
- **Compétences** : Algorithmes minimax, Alpha-Beta, heuristiques
- **Technologies** : IA, théorie des jeux, optimisation
- **Niveau** : Expert/Recherche
- **Applications** : Gaming, systèmes de décision, optimisation

### 2. Développement C++ Avancé (B-CPP-500) 
**Projet** : R-Type - Jeu multijoueur en réseau
- **Compétences** : C++ moderne, ECS, réseau, moteur de jeu
- **Technologies** : C++17/20, architecture distribuée, temps réel
- **Niveau** : Expert/Industrie
- **Applications** : Gaming AAA, systèmes temps réel, simulation

### 3. Développement Full-Stack (B-DEV-500)
**Projet** : Area - Plateforme d'automatisation
- **Compétences** : Architecture full-stack, APIs, microservices
- **Technologies** : Web moderne, cloud native, intégrations
- **Niveau** : Expert/Industrie  
- **Applications** : SaaS, plateformes d'intégration, automation

### 4. DevOps Expert (B-DOP-500)
**Projets** : Bernstein (Infrastructure) + Whanos (PaaS)
- **Compétences** : Kubernetes, Infrastructure as Code, Platform Engineering
- **Technologies** : Cloud native, orchestration, observabilité
- **Niveau** : Expert/Production
- **Applications** : Cloud platforms, enterprise infrastructure

### 5. Programmation Fonctionnelle (B-FUN-500)
**Projet** : GlaDOS - Langage de programmation complet
- **Compétences** : Théorie des langages, compilation, interprétation
- **Technologies** : Haskell/OCaml, parsers, VM design
- **Niveau** : Expert/Recherche
- **Applications** : Compilers, DSLs, language tooling
